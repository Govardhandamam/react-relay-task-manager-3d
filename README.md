This is an extention of [Relay-data-driven-dependencies](https://github.com/relayjs/relay-examples/tree/main/data-driven-dependencies)

## Getting Started

First, run the relay command and then development server:

```bash
npm run relay
# or
yarn relay
```

```bash
npm run dev
# or
yarn dev

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
